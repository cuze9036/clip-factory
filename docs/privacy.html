Privacy Policy

Clip Factory · Last updated November 22, 2026

Uses YouTube API Services

Clip Factory is a personal tool that runs on its owner's own computer and is used only by its owner, to manage the owner's own YouTube channel. This policy explains what data it uses.

YouTube API Services

Clip Factory uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. Google's handling of your data is described in the Google Privacy Policy (www.google.com/policies/privacy).

Data it accesses

With the owner's permission, given on Google's OAuth consent screen, Clip Factory uses these permissions:

  • Upload videos (youtube.upload): to publish short clips to the owner's channel.
  • View the YouTube account (youtube.readonly): to read the view and like counts of those uploads.
  • View YouTube Analytics reports (yt-analytics.readonly): to see which countries the views come from.

How the data is used, stored and shared

  • It is used only to upload the owner's clips and to show the owner how they perform.
  • The OAuth token and the statistics are stored only on the owner's computer, in a file only the owner's Windows account can read. Nothing is stored on any server run by Clip Factory.
  • No Google user data is sold, shared with third parties, or used for advertising. No data from other people's accounts is collected.
  • Clip Factory does not use cookies and does not store or read information on users' devices other than its own token and database files.

Clip Factory's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Keeping and deleting data

  • Video statistics are refreshed every few hours. If they cannot be refreshed (for example after access is removed), they are deleted automatically within 30 days.
  • Remove access at any time on Google's security settings page: security.google.com/settings/security/permissions (also at myaccount.google.com/permissions).
  • Delete all YouTube data with the command clipfactory forget-youtube. It revokes the token at Google, deletes it from the computer, and deletes the stored YouTube statistics right away.
  • After access is removed at Google, the stored token stops working at once.
  • To ask for deletion or for a copy of the data, contact us below; requests are handled within 7 days.
