Clip Factory

Uses YouTube API Services

Clip Factory is a personal tool that runs on its owner's own computer. It finds the best moments in long videos, turns them into short vertical clips with captions, and uploads them to the owner's own YouTube channel as YouTube Shorts.

The videos it clips are the owner's own gameplay recordings and content from creators whose clipping programs allow it. It is used only by its owner and does not offer accounts, sign-ups or services to anyone else.

What it does with YouTube

  • Signs in to the owner's YouTube channel with Google's OAuth consent screen.
  • Uploads short videos to that channel with a title, description, tags and a scheduled publish time (YouTube Data API v3, videos.insert).
  • Reads view and like counts and the viewer country breakdown for those uploads (YouTube Data API v3 and YouTube Analytics API).

By using Clip Factory you agree to be bound by the YouTube Terms of Service.
