# Clip Factory

Owner writes Hindi/Hinglish: reply in simple Hindi, commands in English. Everything the tool produces (captions, titles) stays English for US viewers.

## What it is
Python tool in this folder that earns from Whop clipping campaigns (paid per 1K views) and runs the owner's GTA 6 channel. Each campaign is a lane (sources, rules, budget, quota).
Flow: `discovery.py` (Apify listings every 6 h + #campaign-feed → suggested campaigns → `board.py` cards) → `watcher.py` (YouTube/Twitch/folder/Dropbox share links/Google Drive via `gdrive.py`) → `analyst.py` (Gemini watches the whole video, YouTube or uploaded local files, and writes a scene report; the director (Claude if ANTHROPIC_API_KEY, else free AI) plans clips + edits; report posted on Discord; falls back to `moments.py`) → `download.py` → `render.py` (1080x1920, captions) → `metadata.py` → `review.py` (score ≥ 9 auto-approves) → `schedule.py` (US Eastern slots) → `publish.py` (API where keys exist; else video + caption to Telegram/Discord for the owner to post) → `analytics.py`.

## Where things happen (keep it this way)
- Discord (`discord_bot.py`, `commands.py`): all control, alerts, buttons, commands.
- Telegram (`telegram.py`): only delivers clips the owner posts by hand (video + caption): TikTok, X, and any platform whose API fails. No commands.
- Task "Clip Factory" runs `windows\start.ps1` via `conhost.exe --headless` (no window: Windows Terminal ignored -WindowStyle Hidden, and closing that window killed the runner; a new runner stops pipelines a dead one left): auto-start, crash restart, installs new GitHub commits (and zips dropped in `Desktop\CLIPING TOOL`) within about 30 seconds; restarts the pipeline within ~10 s when `.env` or `config.local.yaml` changes.
- Discord channels: #general (control), #ai-insights (weekly AI review + daily check `health.py` `!check` + safe auto-fixes every 5 min `autofix.py` `!fix`: retries ≤2, Instagram/Facebook → Telegram fallback, extra reminder, free-AI error explanations; code bugs become GitHub issues titled "[auto-report] …" (`bugreport.py`, scrubbed, needs GITHUB_ISSUES_TOKEN) that an hourly Claude Code task fixes), #campaign-updates (live campaigns with priority tags, kept up to date), #active-campaigns (running lanes), #campaign-feed (followed announcement channels the bot reads), #clip-submission (each live campaign clip: "📌 Submit now" + the link alone + ✅ Done; Done deletes them there) and #approved-clips (clips marked ✅ Done). Existing channels only; missing ones fall back to #general.

## Rules
- Never log in to or automate the owner's Whop account.
- Never print or commit `.env`, `secrets\`, tokens.
- Code lives on GitHub: cuze9036/clip-factory (public, no secrets). The laptop installs every new commit on `main` within about a minute (`windows\start.ps1`), replacing this folder's files but keeping keys, data and `config.local.yaml`. So never edit code here without it reaching GitHub: commit and push if this machine can, otherwise send the fix to the owner's main chat. Laptop-only settings go in `config.local.yaml`.
- After code changes: bump `VERSION`, run `python -m pyflakes clipfactory`.
- Read logs with `-Tail 30`, never whole files.
