Privacy Policy

Clip Factory · Last updated November 21, 2026

Clip Factory is a personal tool that runs on its owner's own computer. It is used only by its owner, to manage the owner's own YouTube channel. This policy explains what Google user data it uses.

Data it accesses

With the owner's permission, through Google's OAuth sign-in, Clip Factory uses these YouTube permissions:

  • Upload videos (youtube.upload): to publish short clips to the owner's channel.
  • View the YouTube account (youtube.readonly): to read view and like counts of those uploads.
  • View YouTube Analytics reports (yt-analytics.readonly): to see which countries the views come from.

How the data is used

  • Only to upload the owner's clips and to show the owner how they perform.
  • The sign-in token and statistics are stored only on the owner's computer.
  • No Google user data is sold, shared with third parties, or used for advertising.
  • No data from other people's accounts is collected.

Clip Factory's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Keeping and deleting data

Data stays on the owner's computer until the owner deletes it. Access can be removed at any time at myaccount.google.com/permissions, which stops Clip Factory from using the account.

Contact

Questions about this policy: open an issue at github.com/cuze9036/clip-factory/issues.
