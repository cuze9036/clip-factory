# Clip Factory

Owner writes Hindi/Hinglish: reply in simple Hindi, commands in English. Everything the tool produces (captions, titles) stays English for US viewers.

## What it is
Python tool in this folder that earns from Whop clipping campaigns (paid per 1K views) and runs the owner's GTA 6 channel. Each campaign is a lane (sources, rules, budget, quota).
Flow: `discovery.py` (Apify listings every 6 h + #campaign-feed → suggested campaigns → `board.py` cards) → `watcher.py` (YouTube/Twitch/folder/Dropbox share links/Google Drive via `gdrive.py`) → `analyst.py` (Gemini watches the whole video, YouTube or uploaded local files, and writes a scene report; the director (Claude if ANTHROPIC_API_KEY, else free AI) plans clips + edits; report posted on Discord; falls back to `moments.py`) → `download.py` → `render.py` (1080x1920, captions) → `metadata.py` → `review.py` (score ≥ 9 auto-approves) → `schedule.py` (US Eastern slots) → `publish.py` (API where keys exist; else video + caption to Telegram/Discord for the owner to post) → `analytics.py`.

## Where things happen (keep it this way)
- Discord (`discord_bot.py`, `commands.py`): all control, alerts, buttons, commands.
- Telegram (`telegram.py`): only delivers clips the owner posts by hand (video + caption): TikTok, X, and any platform whose API fails. No commands.
- Task "Clip Factory" runs `windows\start.ps1`: auto-start, crash restart, installs new GitHub commits (and zips dropped in `Desktop\CLIPING TOOL`) within about 30 seconds; restarts the pipeline within ~10 s when `.env` or `config.local.yaml` changes.
- Discord channels: #general (control), #ai-insights (weekly AI review + daily check `health.py` `!check` + safe auto-fixes every 5 min `autofix.py` `!fix`: retries ≤2, Instagram/Facebook → Telegram fallback, extra reminder, free-AI error explanations; code bugs become GitHub issues titled "[auto-report] …" (`bugreport.py`, scrubbed, needs GITHUB_ISSUES_TOKEN) that an hourly Claude Code task fixes), #campaign-updates (live campaigns with priority tags, kept up to date), #active-campaigns (running lanes), #campaign-feed (followed announcement channels the bot reads), #clip-submission (each live campaign clip: "📌 Submit now" + the link alone + ✅ Done; Done deletes them there) and #approved-clips (clips marked ✅ Done). Existing channels only; missing ones fall back to #general.

## Rules
- Never log in to or automate the owner's Whop account.
- Never print or commit `.env`, `secrets\`, tokens.
- Code lives on GitHub: cuze9036/clip-factory (public, no secrets). The laptop installs every new commit on `main` within about a minute (`windows\start.ps1`), replacing this folder's files but keeping keys, data and `config.local.yaml`. So never edit code here without it reaching GitHub: commit and push if this machine can, otherwise send the fix to the owner's main chat. Laptop-only settings go in `config.local.yaml`.
- After code changes: bump `VERSION`, run `python -m pyflakes clipfactory`.
- Read logs with `-Tail 30`, never whole files.

Selftest all OK; it also checks the Instagram/Facebook keys ("Instagram posting", "Facebook posting").
Join flow: #campaign-updates card → Open campaign → join on Whop (owner) → I joined (card moves to #active-campaigns at once as ⏳ JOINED, NOT RUNNING YET) → paste the page / 🎬 Footage links → lane starts (▶ RUNNING).
Posting: YouTube = automatic via the API (Google closed the audit on 2026-11-23: API uploads are not forced private, an upload costs 100 quota units; `always_manual: []`, `youtube_uploads_per_day: 10`). Instagram + Facebook = Meta Graph API once keys are set (IG_MAIN_USER_ID, IG_MAIN_TOKEN, FB_MAIN_PAGE_ID, FB_MAIN_PAGE_TOKEN), else Telegram. TikTok + X = Telegram, owner posts. Hand-posted clips reach Telegram up to 24 h early (with the time in ET and IST); Discord reminds 30 min before the slot (`manual_posting`). Slots per platform are in `schedule.platform_slots` / `manual_slots` (US evening peaks; manual ones fit IST waking hours), ±12 min jitter. X API (credits + keys X_API_KEY, X_API_SECRET, X_ACCESS_TOKEN, X_ACCESS_SECRET) is for later; nothing to do now. No screen/remote-desktop automation of any platform.
Google Drive (`gdrive.py`): any Drive/Docs link given as footage is explored: guide docs are read, links inside them followed (videos folders, Dropbox, YouTube), video folders become `gdrive` sources downloaded every few hours. Private folders need `clipfactory auth-drive main` once (read-only, Drive API enabled). Links it can't open (private Drive, mega/WeTransfer/OneDrive…, private or subscriber-only Twitch/YouTube, dead Dropbox) get one simple Discord note: link → what to do (`gdrive.simple_help`); saved in `blocked_links` and given to the campaign check. Twitch channels, VODs and clips are footage (yt-dlp).
Deep reading: every Drive folder/file and Google Doc on a pasted or fetched campaign page is explored (up to 10 links, 8 levels deep, 150 items), and links inside docs are followed (Drive, Docs, Dropbox, YouTube, Twitch, Kick, Vimeo, Streamable, direct .mp4/.mov files).
Whop links (`whop_page.py`, whop.com and contentrewards.com): `!campaign <whop link>` or a Whop link after I joined / 🎬 Footage: the public page is downloaded with no login and no cookies (never the owner's account) and read like a pasted page (brief, hidden page data, Docs/Drive/Dropbox/YouTube/Twitch links); a login wall → asks for a paste. Running campaigns with a readable page are re-read every 6 h (only a changed page is applied).
Flops (`flops.py`, `flops:`): a clip under 300 views (or the campaign's min_views) 48 h after posting (YouTube/IG/FB) → one more clip a day for that campaign (max 2× quota) and, unless the rules forbid reposts, one new version of the moment (other style, tighter start, stronger titles). Submit reminders (`publish.submit_reminder`, `submit:` in config) go out for every campaign post, even without a saved campaign link: one message "📌 Submit now: <campaign> · <Platform> Reel/Short N · submit by <ET (IST)>" with a ✅ Done button, then the link alone (easy copy); one more ping after 20 min if not marked Done. The owner submits on Whop by hand.
Campaign check (`check.py`, `!fit`): before a campaign's first video is watched, the AI reads the whole page + Drive guide docs (raw text kept in `guide_text`) + rules against what the tool can/can't do: ✅ go / 🟡 partial → clipping goes on; ⛔ no → lane paused, ▶ Resume runs it anyway. Account rules (name, profile picture, new public account) and the owner's to-do go to Discord and the card. Re-runs when page/guide/rules change.
Campaign guide (`guide.py`, `!guide`): the pasted page and reference material become do/avoid lines in every AI prompt. Each #active-campaigns card has 📋 Guide / 🎬 Footage / ⏸ Pause buttons: the next paste goes to that campaign only; with several campaigns and no id, commands ask which. Google Docs/Slides/Sheets links shared with "anyone with the link" are read directly; long pastes arrive as message.txt and are read too.
Edit styles (`styles.py`, from the viral-clip research): bold_crop, word_pop, blur_box, black_title, meme_top, split; picked per clip from the campaign topic (varied; a remake/re-edit of the same moment never repeats a style until all were tried, `styles_used:<moment>`), accent colour per topic, only the first @handle on screen, fonts auto-downloaded to assets/fonts; `render.style` can fix one; weekly review reports views per style.
Effects (`effects.py`, `effects:` in config): every styled clip gets an edit plan (auto from word timing now; an AI director can pass its own, same keys, cleaned/clamped): jump cuts of long pauses, face-following 9:16 crop (OpenCV YuNet), hook text over the first ~1.8 s, punch zooms + whoosh on strong words, a white flash, shake on '!', Twemoji over captions, emphasised words bigger. The plan used is stored in `clips.plan`. Footage that already has captions burned in (auto-detected per video, `effects.has_burned_captions`) gets none of ours, no emoji/hook over it, and a whole-frame style; each campaign card has 💬 Captions auto/on/off (`!captions`).
Review cards show the style; approve/auto-approve replies list each platform, time (ET + IST) and who posts; `!queue` shows what goes out next.
Review cards have 🔁 Re-edit (`reedit.py`, `!reedit`): new titles, start earlier/later, longer/shorter, different style, different moment, or a typed note the free AI turns into those changes.
Paid campaigns: #Sponsored (or the campaign's #<Brand>Ad) on the first line of every caption; YouTube paid-promotion flag.
AI router (`llm.py`): text work tries `llm.text_order` (free-llm → gemini → ollama); watching videos uses Gemini only (local files are uploaded to Gemini); with ANTHROPIC_API_KEY, Claude (claude-opus-5-5, `daily_budget_usd` 0.50) does only `llm.claude_tasks` first; `!ai` shows usage and Claude spend.
Weekly self-review (`insights.py`, `!insights`): free AI only (Gemini / FreeLLMAPI, never Claude) reads last week's views by platform, slot, moment type, campaign; saves title/moment tips into every AI prompt and skips a clearly weak slot (bounded); everything else is a suggestion on Discord.
Languages: footage in any language is used (Whisper `multilingual_model` translates speech into English captions; titles/hooks always English) unless the campaign's rules or guide say English only (`analyst.english_only`), or `moments.english_only: true`.
Keys go in with `windows\set-key.ps1 <NAME>` (hidden input), never in chat.
